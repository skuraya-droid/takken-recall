# 宅建 アクティブリコール

宅地建物取引士試験（全4科目・200問）のアクティブリコール暗記カードです。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（見た目と動作） |
| `data.js` | **問題データ。カードの追加・修正はここだけ触ります** |
| `manifest.json` | スマホのホーム画面に追加したときの設定 |
| `build.py` | 上の2つを1ファイルに結合するスクリプト |
| `takken-single.html` | 結合済みの単一ファイル版（メール添付や単体配布用） |

---

## 1. Webページとして公開する

### 方法A：GitHub Pages（おすすめ・無料・更新が楽）

継続的に改修していくならこれが一番向いています。変更履歴が残り、修正のたびに再アップロードするだけで反映されます。

1. GitHub でリポジトリを新規作成（例：`takken-recall`）。**Public** にする
2. `index.html` `data.js` `manifest.json` をアップロード（ドラッグ&ドロップでOK）
3. リポジトリの **Settings → Pages** を開く
4. Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
5. 1〜2分後、`https://ユーザー名.github.io/takken-recall/` で公開されます

以降の更新は、`data.js` を書き換えてアップロードし直すだけです。

### 方法B：Cloudflare Pages / Netlify Drop（アカウント作成だけ・数十秒）

- Netlify Drop（<https://app.netlify.com/drop>）にフォルダごとドラッグ&ドロップ
- Cloudflare Pages も同様に「Direct Upload」で可能

手軽ですが、更新のたびに再アップロードが必要です。

### 方法C：ファイルを直接開く

`takken-single.html` をスマホやPCに保存してダブルクリックすれば、サーバーなしでも動きます。ただしURLで共有はできません。

### スマホのホーム画面に追加する

公開したURLをスマホのブラウザで開き、共有メニューから「ホーム画面に追加」。アプリのように全画面で起動します。

## 2. 学習記録の保存について

記録の保存先は**自動で切り替わります**（画面下部に表示されます）。

- **Claudeの中で開いたとき** → Claudeの保存領域
- **Webページとして開いたとき** → そのブラウザの保存領域（localStorage）

そのため、**PCとスマホでは記録が別々になります**。端末をまたぐときは：

1. 元の端末で **⬇ バックアップ** → JSONファイルが保存される
2. そのファイルを別端末に送る
3. 別端末で **⬆ 復元** → 読み込む

ブラウザの履歴を消すと記録も消えるため、**月に一度はバックアップ**を取っておくと安心です。

## 3. カードを追加・修正する

`data.js` を開き、該当の科目・単元の `cards` 配列に追記します。

```js
{ id:"kn52", q:"ここに問い（キーワード）", a:[
  "解答の1行目。<b>太字</b>が使えます",
  "解答の2行目"
], trap:"ひっかけポイント（省略可）"},
```

### ルール

- **`id` は全科目を通して重複させない**こと。重複すると学習記録が混ざります
  - 接頭辞の目安：業法 `a`〜`p`／権利関係 `kn`／法令上の制限 `hr`／税・その他 `ze`
- `a` は配列。1行が1つの箇条書きになります
- 使えるタグは `<b>` 程度に留めておくと崩れません
- **`id` を変更すると、そのカードの学習記録はリセットされます**（別カード扱いになるため）

### 単元・科目を増やす

単元を増やす場合は `units` に `{ unit:"17. 新しい単元", cards:[ ... ] }` を追加。
科目を増やす場合は新しい定数を作り、ファイル末尾の `TAKKEN_DATA = [...]` に加えれば、アプリ側の修正は不要です。

### 修正後にやること

```bash
python3 build.py     # takken-single.html を作り直す
```

GitHub Pages を使っている場合は `data.js` を上げ直すだけでよく、この作業は単一ファイル版が必要なときだけで構いません。

## 4. 復習ペースを変える

`index.html` の中ほどにある次の行を書き換えます（単位は日）。

```js
const INTERVALS = { batsu: 1, sankaku: 3, maru: [7, 14, 30, 60] };
```

- `✕` を付けたカードは翌日、`△` は3日後に「今日やる」へ戻ります
- `◯` は連続で正解するほど間隔が延びます（7日 → 14日 → 30日 → 60日）
- 試験直前は `maru: [3, 5, 7, 10]` などに詰めると回転が上がります

## 5. 定期メンテナンスの目安

| 時期 | やること |
|---|---|
| 毎月 | バックアップを取る／解いていて曖昧だった論点をカードに追加 |
| 法改正の公表時（毎年春） | 改正論点の数字を確認して `data.js` を修正 |
| 試験直前期 | 「統計」単元に最新の公表値を記入。`INTERVALS` を短くする |

### 注意：統計の単元について

「税・その他」の**統計は、見るべき資料の一覧のみ**を収録しています。地価公示・建築着工統計などの数値は毎年変わるため、本試験の年の最新の公表値をご自身で確認して追記してください。

法令の内容は作成時点のものです。改正の可能性があるため、直近の公式資料やテキストと突き合わせてご利用ください。
