同期設定

設定すると、解答するたびに自動保存され、開いたときに自動で取り込みます。端末をまたいでも記録が揃います。

Settings → Developer settings → Personal access tokens → Fine-grained tokens で発行します。対象はこのリポジトリのみ、権限は Contents: Read and write だけで足ります。トークンはこの端末のブラウザにのみ保存されます。
同梱の code.gs を Google Apps Script に貼り付け、ウェブアプリとしてデプロイしたURLを入れてください。
